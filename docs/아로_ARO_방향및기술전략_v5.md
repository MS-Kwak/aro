## 1. 왜 지금인가 — 소상공인의 현실

2026년 현재 국내 1인 자영업자는 422만 명으로 전체 자영업자의 74.7%입니다. 이들 대부분은 하루 종일 혼자 카운터를 지키며 리뷰 답변, 단골 관리, 쿠폰 이벤트를 전부 손으로 처리합니다. 디지털 도구가 넘쳐나지만 배우기 어렵고, 서비스마다 따로 가입해야 하는 번거로움 때문에 결국 종이 쿠폰과 감(感)에 의존하는 사장님이 태반입니다.

## 2. 경쟁사 현황 — 각자 조각만 갖고 있다

시장에는 이미 여러 서비스가 있습니다. 그런데 공통적인 문제가 있어요. 기능이 파편화되어 있습니다. 단골 관리만 하거나, 리뷰 답변만 하거나, 카카오 마케팅만 합니다. 사장님 입장에서는 서비스를 여러 개 써야 하고, 각각 배워야 하고, 각각 비용을 내야 합니다.

**결론:** 경쟁자들이 조각을 따로따로 팔 때, 아로는 AI 하나가 전부 처리하는 통합 서비스입니다. 지금 이 조합을 하나로 묶은 서비스는 없습니다.

## 3. 아로가 가야 할 방향

카카오 채널 생성·관리는 사장님마다 수동으로 처리해야 하고 카카오 정책상 자동화가 불가능합니다. 100개 가게가 생기면 100번 반복해야 하는 구조라 스케일하기 어렵습니다. 이 문제를 인식하고 방향을 전환합니다.

### 3-1. 핵심 전환: 카카오 채널은 선택 옵션으로

카카오 채널이 없어도 핵심 기능이 작동하도록 설계합니다. QR 스탬프 → 손님 전화번호 수집 → 알림톡 자동 발송 흐름은 카카오 채널 없이 완전 자동화됩니다. 채널은 원하는 사장님만 나중에 추가하는 옵션입니다.

## 4. 카카오 채널 연동 — 구조와 한계

카카오 채널은 핵심이 아니라 부가 기능으로 재정의합니다. 구조를 이해하면 왜 그래야 하는지 분명해집니다.

<img src="media/05ba7248822cac338dd18409219aefdc6879ee25.png" style="width:5.41667in;height:4.46875in" />

**채널은 사장님 소유, 아로는 AI 챗봇으로 연결됩니다.** 카카오 채널은 사장님이 본인 계정으로 개설하거나(어려운 분은 아로가 대행), 아로가 그 채널에 AI 챗봇으로 연결됩니다. 손님이 카카오 채널에 DM을 보내면 아로 AI가 자동 응대합니다.

### 4-1. 카카오 마케팅 자동화 — 가능 범위

| **방식**       | **내용 및 제약**                                                                                                                    | **아로 적용 단계** |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| 알림톡 (핵심)  | 정보성 메시지. 채널 없이 전화번호만 있으면 발송 가능. 건당 8원(+VAT). 이탈 단골 쿠폰에 활용. 딜러사(솔라피·비즈고 등) API 통해 연동 | 1단계 MVP          |
| 브랜드 메시지  | 광고성 메시지. 채널 친구 추가한 손님에게만 발송 가능. 건당 약 23~25원. 이벤트·프로모션·쿠폰 자유 활용                               | 2단계 (확장)       |
| 챗봇 Event API | 트리거 기반 자동 발송. Supabase 이탈 감지 → API 호출 → 메시지 발송 흐름으로 구현                                                    | 2단계              |

### 4-2. 채널 생성 자동화 — 불가 판정

카카오 채널 자동 생성은 카카오 정책상 불가능합니다. 채널 하나당 사장님 본인의 카카오 사업자 계정이 필요하고, 심사 기간이 영업일 기준 3~5일 소요됩니다. 100개 가게가 생기면 100번 수동으로 처리해야 하는 구조라 스케일이 안 됩니다.

**해결책:** 1단계 MVP는 채널 없이 알림톡만으로 핵심 기능(이탈 쿠폰 발송)을 구현합니다. 채널은 원하는 사장님이 선택적으로 추가하는 옵션으로 내립니다. 스케일 문제가 사라집니다.

| **1단계 MVP**    | ① 사장님 셀프 가입 + 가게 정보 등록 (Next.js 웹) ② QR 스탬프 적립 (손님 전화번호 수집) ③ 단골 대시보드 (방문 횟수·최근 방문일 조회) ④ 알림톡 이탈 쿠폰 발송 (3주 미방문 자동 감지) ⑤ AI 리뷰 자동 답변 (네이버·카카오맵·구글) | 가입 후 2주 내 QR 실제 부착 비율 (활성화율) | 2~3개월  |

| 유료 고객 획득 비용 (CAC) | 10~20만원              | 온라인 광고 기준                      |
| 유료 고객 연간 가치 (LTV) | 48만원+                | 월 4만원 × 12개월                     |
| 활성화율 (핵심 검증 지표) | 가입 후 2주 내 QR 부착 | 이게 무너지면 광고비가 전부 새는 구조 |

### 7-3. 24개월 시나리오

| **시나리오** | **12개월 차**  | **24개월 차**  | **전제**                      |
| ------------ | -------------- | -------------- | ----------------------------- |
| 보수         | 월 80만원      | 월 200만원     | 본업 병행, 완만한 성장        |
| **기본**     | **월 200만원** | **월 520만원** | **12개월 차부터 마케팅 강화** |
| 낙관         | 월 400만원     | 월 1,200만원   | 업종 내 바이럴 확산           |

인프라 고정비는 월 10~30만원 수준이며, 유료 가게 약 10곳이면 운영비 손익분기를 넘습니다. 마케팅 비용 포함 실질 손익분기는 15~18개월 차로 추정합니다.

## 8. 고객 획득 전략 — 오프라인 영업 없이 온라인 100%

두 원칙으로 운영합니다.

### 8-1. 제품이 영업사원: 셀프서브 온보딩

사장님이 광고를 보고 가입 → 5분 안에 QR 스탬프 PDF 출력 → 카운터에 부착. 아무와도 통화하지 않고 끝납니다. 제품 안에서 데이터가 쌓이며 '3주 미방문 단골 8명, 쿠폰 보낼까요?' 제안이 뜨는 순간이 유료 전환 포인트입니다.

### 8-2. 업종 버티컬 마케팅

제품은 처음부터 전 업종 지원합니다. 하지만 마케팅 첫 타겟은 개인 카페로 집중합니다. 카페 사장님은 인스타에서 서로 팔로우하는 촘촘한 네트워크라, 성공 사례 하나가 나오면 업종 안에서 빠르게 확산됩니다. 카페 레퍼런스를 만든 뒤 네일·미용실·필라테스 커뮤니티로 마케팅을 넓힙니다.
