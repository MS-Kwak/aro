소상공인 AI 단골 관리 플랫폼

_사장님의 마음에, 손님의 마음에 아로새기다_

# **1. 한눈에 보는 요약**

'아로(ARO)'는 소상공인 가게(카페·네일샵·미용실 등)에 QR 스탬프 기반 단골 관리와 카카오톡 채널 AI 자동응대를 제공하는 B2B SaaS 플랫폼입니다. 서비스명은 '아로새기다'에서 따왔습니다 — 손님이 스탬프를 새기고, 가게가 단골을 마음에 새기는 서비스의 본질을 담은 이름입니다.

핵심 전략은 오프라인 영업 없이 100% 온라인으로 사장님을 획득하는 것입니다. 광고를 보고 들어온 사장님이 5분 안에 스스로 가입을 끝내는 셀프서브(Self-serve) 구조와, 지역이 아닌 업종(개인 카페) 중심의 버티컬 마케팅이 그 수단입니다.

아로는 AI 응대 자동화(ARO)와 단골 관리 플랫폼을 하나의 브랜드, 하나의 개발 로드맵으로 통합한 서비스입니다. 정부지원사업(혁신 소상공인 AI 활용지원)에 신청한 이름과의 연속성도 유지됩니다. 개발은 Next.js 중심으로 진행하고, 앱 스토어 배포 시 React Native로 래핑하는 방식으로 개발 부담을 최소화합니다.

| **타깃 고객**         | 1차: 개인 카페 사장님 / 2차: 네일·미용실·필라테스 등 단골 업종  |

# **2. 왜 이 사업인가**

## **2-1. 시장의 빈자리**

소상공인 단골 관리 시장에는 이미 경쟁자가 있습니다. 도도포인트(네이버 계열사 플레이스앤 운영)는 2026년 5월 네이버 플레이스·지도와 데이터 연동을 완료하며 오히려 강화됐고, 누적 사용자 3,500만 명의 기반을 갖추고 있습니다. 페이히어는 클라우드 POS 기반으로 2026년 4월 기준 전국 8만 5,000개 이상 매장에서 사용 중이며, 포인트·스탬프 적립과 알림톡 자동 마케팅까지 제공합니다. 그러나 이들 경쟁자에게는 공통적인 공백이 있습니다. 도도포인트와 페이히어 모두 태블릿·POS 단말기 하드웨어 설치가 필요하고, 카카오톡 채널 AI 자동응대 기능은 없습니다. 또한 네이버 플레이스 중심으로 설계되어 카카오 채널을 주 소통 채널로 쓰는 사장님들에게는 맞지 않습니다. 아로는 이 공백을 파고듭니다. QR 프린트 한 장으로 시작하는 설치 없는 구조, 카카오톡 채널 AI 자동응대, 이탈 단골 자동 쿠폰 발송을 하나로 묶어, 하드웨어 없이 시작하고 싶은 소상공인을 위한 경량 대안으로 포지셔닝합니다.

## **2-2. 우리가 가진 강점**

- **ARO 통합 개발 —** LLM/RAG 기반 AI 응대 자동화(카카오톡·인스타 DM·네이버 톡톡) 설계가 완료되어 있으며, 본 플랫폼과 병행 개발하여 유료 티어의 킬러 기능으로 탑재. 정부지원사업(혁신 소상공인 AI 활용) 스토리와도 직결

- **mapstory 기술 자산 —** mapstory 개발로 확보한 지도 기반 서비스 코드 자산 보유 (기술 검증 완료)

- **팀 —** 프론트엔드·백엔드 개발(민서) + DB 설계·기획(황형/보노보플랫폼)의 검증된 장기 협업 체제. 아이디어와 핵심 의사결정은 공동 협의

- **기술 —** Next.js + Supabase 중심 개발, 앱은 React Native 래핑으로 스토어 배포 — 웹/앱 코드베이스를 하나로 유지해 개발 리스크 최소화

## **2-3. 선순환 구조**

① 사장님 온라인 광고 유입 → 셀프 가입 → QR 스탬프 카운터 부착 → ② 손님이 스탬프 적립(소비자 유저 자동 확보) → ③ 단골 데이터 누적 → ④ '3주째 안 온 단골 8명에게 쿠폰 보낼까요?' AI 제안 → ⑤ 재방문 증가 → 사장님이 유료로 전환. 소비자를 별도 광고로 모을 필요 없이, 사장님이 카운터에서 '아로 적립하세요' 한마디로 유저를 만들어주는 구조입니다.

## **3-2. PLG: 제품이 영업사원**

무료 스탬프는 미끼가 아니라 데이터 축적 장치입니다. 사장님이 무료로 쓰는 동안 단골 방문 데이터가 쌓이고, 'AI가 재방문을 만들어준다'는 가치가 수치로 보이는 순간이 유료 전환 시점입니다. 사람이 영업하지 않아도 제품 안에서 유료 전환이 일어나는 PLG(Product-Led Growth) 구조입니다.

# **4. 카카오톡 채널 연동 구조**

소상공인들은 이미 카카오톡 채널을 보유하고 있거나, 쉽게 개설할 수 있습니다. 아로는 그 채널에 AI 챗봇으로 연결되는 방식이며, 채널의 소유권은 어디까지나 사장님에게 있습니다. 아래 그림은 이 구조를 보여줍니다.

<img src="media/image3.png" style="width:6.26806in;height:5.16181in" />

## **4-1. 채널 소유 구조**

카카오 채널의 소유권은 사장님에게 있습니다. 채널 개설은 두 가지 방식을 지원합니다. 첫째, 사장님이 카카오 비즈니스 계정으로 직접 개설하는 방식. 둘째, 사장님이 카카오 계정을 제공하면 아로가 대신 채널을 개설해드리는 대행 방식 — 디지털 환경이 익숙하지 않은 사장님을 위한 옵션으로, 채널 소유권은 여전히 사장님에게 있습니다. 두 경우 모두 개설된 채널에 아로 AI를 챗봇으로 연결하는 방식은 동일합니다.

## **4-2. 연동 방식**

| **기능**           | **설명**                                                                                                                       | **단계**     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| 카카오 알림톡 발송 | 사장님이 대시보드에서 '이탈 단골 쿠폰 발송' 실행 시, 손님 카카오톡으로 자동 메시지 발송. 발송 단가 약 8~15원으로 구독료에 포함 | 1단계 (MVP)  |
| 카카오톡 채널 챗봇 | 손님이 가게 카카오 채널에 DM 발송 시 ARO AI가 자동 응대. 영업시간·메뉴·예약 등 FAQ 자동 처리                                   | 2단계        |
| 인스타그램 DM 연동 | 인스타 DM으로 들어오는 문의도 ARO AI가 통합 응대                                                                               | 2단계 (확장) |

## **4-3. 온보딩 흐름**

사장님이 아로 가입 후 '카카오 채널 연동' 버튼 클릭 → 카카오 비즈니스 계정 OAuth 인증 → 아로가 해당 채널에 챗봇으로 자동 등록. 단, 카카오 채널 신규 개설 시 심사에 1~2주가 소요될 수 있어 온보딩 안내 UX에 대기 시간을 명시합니다.

# **5. 온라인 고객 획득 전략 (GTM)**

## **5-1. 원칙 ① 셀프서브 온보딩**

사장님이 광고 클릭 후 아무와도 통화하지 않고 가입을 끝낼 수 있어야 합니다. 목표는 '가입 → 가게 정보 입력 → QR 스탬프 PDF 다운로드 → 카운터 부착'까지 5분. 온보딩 중 이탈 구간을 데이터로 추적해 지속 개선합니다.

## **5-2. 원칙 ② 업종 버티컬 마케팅**

제품은 처음부터 전 업종(카페·네일·미용실·필라테스·식당 등 모든 소상공인)을 지원합니다. 가입 시 업종만 선택하면 되며, 기능 자체는 업종에 관계없이 동일합니다. 다만 마케팅 첫 타겟은 개인 카페에 집중합니다. 카페 사장님은 인스타에서 서로 팔로우하는 촘촘한 네트워크를 형성하고 있어, 성공 사례 하나가 나오면 같은 업종으로 빠르게 확산되기 때문입니다. 카페에서 초기 성공 사례(레퍼런스)를 만든 뒤 네일·미용실·필라테스 등 다른 단골 업종 커뮤니티로 마케팅을 넓혀가는 순서입니다.

## **7-2. 단계별 개발 범위**

| **단계**                | **범위**                                                                                                                            | **검증 목표**                             |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **1단계 MVP (2~3개월)** | 사장님 셀프 온보딩(웹), QR 스탬프 적립·쿠폰, 단골 대시보드, 카카오 알림톡 발송, 소비자용 적립 웹앱(설치 없는 웹 우선)               | 활성화율: 가입 사장님의 QR 실제 부착 비율 |
| 2단계 (+2~3개월)        | ARO 코어 개발(AI 응대·이탈 단골 감지 → 자동 쿠폰), 카카오톡 채널 챗봇 연동, 인스타 DM 연동, 유료 결제, RN 웹뷰 래핑으로 스토어 출시 | 무료 → 유료 전환율 (목표 35%)             |

ARO를 별도 제품으로 먼저 완성한 뒤 연동하는 것이 아니라, 2단계부터 본 플랫폼 안에서 ARO 코어를 개발·적용합니다. 하나의 Supabase 기반 위에서 두 기능이 자라므로 개발 리소스가 분산되지 않고, 향후 ARO를 독립 서비스로 분리할 때 이 플랫폼의 가게들이 첫 레퍼런스 고객이 됩니다.

## **7-3. 개발 일정 (안)**

민서의 LG CNS GCAS 프로젝트가 9월 UAT 후 종료되는 일정을 고려하여, 7~9월은 설계·프로토타입 병행 개발, 10월부터 풀타임 투입해 연내 1단계 MVP 출시, 2027년 상반기 내 2단계까지 완료를 목표로 합니다.

# **8. 카카오 자동 마케팅 기술 검토 및 경쟁사 분석**

## **8-1. 카카오 채널 자동 마케팅 가능 여부**

카카오 채널을 통한 자동 마케팅은 기술적으로 구현 가능하며, 메시지 종류에 따라 세 가지 방식으로 나뉩니다.

| **방식**           | **내용 및 제약**                                                                                                                                                                         | **ARO 적용 단계** |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| **알림톡**         | 정보성 메시지. 채널 미추가 손님에게도 발송 가능. 건당 8원(+VAT)으로 가성비 최고. 이탈 단골 재방문 쿠폰은 정보성으로 인정 가능. 공식 딜러사(솔라피·비즈고·팝빌 등) API 통해서만 연동 가능 | 1단계 (핵심)      |
| **브랜드 메시지**  | 광고성 메시지. 카카오 채널을 추가한 고객에게만 발송 가능. 채널 친구 약 23~25원/건. 이벤트·프로모션·쿠폰 등 자유롭게 활용. 스탬프 적립 시 채널 추가 유도 흐름으로 친구 수 확보            | 2단계 (확장)      |
| **챗봇 Event API** | 트리거 기반 자동 발송. Supabase에서 이탈 감지 → Event API 호출 → 카카오 메시지 발송 흐름. 광고성 내용 포함 시 설정 필요. ARO 자동 응대의 핵심 실행 엔진                                  | 2단계             |

딜러사 API 비용은 발송 단가 기준이라 초기 고정비가 거의 없습니다. 솔라피, 비즈고, 팝빌, NHN Cloud 등 공식 딜러사 중 하나와 계약하면 되며, 민서 개발 스펙으로 충분히 구현 가능한 수준입니다.

## **8-2. 경쟁사 분석**

소상공인 단골 관리 시장에는 이미 경쟁자가 존재합니다. 단, 각 서비스는 하드웨어 의존성 또는 네이버 플랫폼 중심이라는 공통된 한계를 갖고 있으며, 아로는 이 공백을 집중 공략합니다.

| **서비스**                          | **특징 및 강점**                                                                                                                              | **한계**                                                         | **규모**               |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------- |
| 도도포인트 (네이버 계열 플레이스앤) | 포인트·스탬프 적립, 이탈 고객 자동 쿠폰, 2026년 5월 네이버 플레이스·지도 실시간 연동 완료. 첫 방문·생일·미방문 기간별 타겟 마케팅             | 태블릿 하드웨어 설치 필요. 카카오 채널 AI 응대 없음. 네이버 중심 | 누적 사용자 3,500만 명 |
| 페이히어                            | 클라우드 POS 기반. 포인트·스탬프 적립, 재방문 쿠폰·생일 쿠폰·알림톡 자동 마케팅. 네이버 플레이스·당근 비즈 프로필 동시 연동                   | POS 단말기 구매 필요(초기 비용). 카카오 채널 AI 응대 없음        | 전국 8만 5,000개+ 매장 |
| 채널톡                              | 고객 리스트 관리, 알림톡·브랜드 메시지 발송, 행동 기반 자동 캠페인. 온라인 쇼핑몰·IT 기업 중심                                                | 오프라인 소상공인용 QR 스탬프 없음. 가격 부담 큼                 | 온라인 사업자 중심     |
| **아로 (ARO)**                      | **QR 프린트 한 장으로 시작. 하드웨어 불필요. 카카오 채널 AI 자동응대(경쟁자 無). 이탈 단골 자동 쿠폰. 전 업종 지원, 마케팅은 카페 집중 시작** | 초기 브랜드 인지도 부족. 빠른 레퍼런스 확보가 관건               | **개발 중**            |

경쟁의 핵심은 결국 세 가지 차별점입니다. 첫째, 카카오 채널 AI 응대(경쟁자 전무). 둘째, 하드웨어 없는 QR 진입(도도포인트·페이히어 대비 진입장벽 최저). 셋째, 카카오 생태계 중심(도도포인트·페이히어의 네이버 중심 대비). 이 세 가지가 아로의 실질적 해자입니다.
