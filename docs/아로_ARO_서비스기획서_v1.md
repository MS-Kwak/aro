### 1-3. 핵심 가치 제안

경쟁사들은 기능을 파편화해서 팝니다. 단골 관리만, 리뷰 답변만, 알림톡만. 사장님은 서비스를 여러 개 가입하고 각각 배워야 합니다. 아로는 이 세 가지를 AI 하나가 처리하는 통합 서비스입니다.

|                | **기존 방식**                 | **아로**                                   |
|----------------|-------------------------------|--------------------------------------------|
| 리뷰 관리      | 매일 직접 확인, 손으로 답변   | AI가 자동 답변 초안 생성 → 원클릭 등록     |
| 단골 관리      | 종이 쿠폰 또는 감(感)에 의존  | QR 스탬프로 자동 수집, 대시보드에서 한눈에 |
| 이탈 고객 관리 | 이탈 여부 파악조차 어려움     | AI가 자동 감지 → 알림톡 쿠폰 자동 발송     |
| 채널 응대      | 카카오 DM 방치 또는 수동 응대 | AI 챗봇 자동 응대 (2단계 유료 서브옵션)    |

### 3-1. \[무료\] QR 스탬프 단골 관리

| **항목**    | **내용**                                                                         |
|-------------|----------------------------------------------------------------------------------|
| 기능 설명   | 손님이 QR코드를 스캔하면 전화번호를 입력하고 스탬프가 적립됩니다                 |
| QR 발급     | 사장님이 대시보드에서 QR PDF 생성 → 프린트 → 카운터에 부착                       |
| 손님 동작   | 카메라로 QR 스캔 → 웹앱 열림 → 전화번호 입력 → 스탬프 적립 완료 (앱 설치 불필요) |
| 적립 데이터 | 전화번호 + 방문 일시 → Supabase 자동 저장                                        |
| 대시보드    | 사장님이 단골 목록, 방문 횟수, 최근 방문일, 이탈 위험 단골을 한눈에 확인         |
| 쿠폰 설정   | N회 적립 시 자동 쿠폰 발급 조건 설정 (예: 10회 적립 시 아메리카노 무료)          |

### 3-2. \[무료\] AI 리뷰 자동 답변

| **항목**         | **내용**                                                                           |
|------------------|------------------------------------------------------------------------------------|
| 지원 플랫폼      | 네이버 플레이스, 카카오맵, 구글 지도, 배달의민족, 쿠팡이츠 (단계적 확장)           |
| 동작 방식        | 플랫폼에서 리뷰 수집 → AI가 감정 분석(긍정·부정·중립) → 상황에 맞는 답변 초안 생성 |
| 사장님 동작      | 대시보드에서 답변 초안 확인 → 수정하거나 그대로 → 원클릭으로 플랫폼에 등록         |
| 무료 범위        | 리뷰 수집 + 답변 초안 생성 + 수동 등록                                             |
| 유료 전환 포인트 | 자동 등록(검토 없이 AI가 바로 게시)은 유료 티어에서 제공                           |
| 알림             | 새 리뷰 등록 시 사장님에게 알림 발송 (앱 푸시 또는 문자)                           |

### 3-3. \[무료 조회 / 유료 발송\] 이탈 단골 감지 및 쿠폰 발송

| **항목**    | **내용**                                                                     |
|-------------|------------------------------------------------------------------------------|
| 이탈 기준   | 기본값: 마지막 방문 후 21일 경과. 사장님이 대시보드에서 기준일 조정 가능     |
| 무료 기능   | 이탈 위험 단골 목록 조회 및 인원 수 확인 (발송 버튼은 잠금)                  |
| 유료 기능   | 알림톡 쿠폰 자동 발송. AI가 매일 이탈 감지 → 설정된 쿠폰 내용으로 자동 발송  |
| 쿠폰 내용   | 사장님이 미리 쿠폰 템플릿 설정 (예: '오랜만이에요! 아메리카노 1,000원 할인') |
| 발송 채널   | 카카오 알림톡 (딜러사 API). 전화번호만 있으면 카카오 채널 없이 발송 가능     |
| 발송 단가   | 건당 약 8원(+VAT). 월 구독료에 기본 발송량 포함                              |
| 자동화 수준 | 사장님이 아무것도 하지 않아도 매일 자동 실행. 발송 결과는 대시보드에서 확인  |

### 3-4. \[유료 서브 옵션\] 카카오 채널 AI 챗봇

카카오 채널은 필수가 아닌 선택 옵션입니다. 원하는 사장님만 연동합니다.

| **항목**    | **내용**                                                                                 |
|-------------|------------------------------------------------------------------------------------------|
| 대상        | 카카오 비즈니스 채널을 보유한 사장님 (없으면 아로가 개설 대행)                           |
| 동작 방식   | 손님이 가게 카카오 채널에 DM 발송 → ARO AI가 자동 응대                                   |
| 응대 범위   | 영업시간, 메뉴, 예약, 위치 등 FAQ. RAG 기반으로 가게 정보 학습                           |
| 채널 소유권 | 사장님 본인 계정 소유. 아로가 챗봇으로 연결되는 구조                                     |
| 채널 생성   | 사장님 직접 개설 또는 아로 대행 (카카오 심사 3~5 영업일 소요)                            |
| 주의사항    | 카카오 정책상 채널 자동 생성 불가 → 100개 가게 = 100번 수동. 스케일 한계로 서브옵션 처리 |
